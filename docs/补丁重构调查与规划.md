## 1. 项目背景（现状复核）

- **对象**：MATERIA 内置人格 さくら 的 SHIORI `first.dll`（Delphi，890,880B，
  MD5 `A380E8E5AC1BCE5BE28E067D19749DDE`）。移植到 SSP + 全面汉化。
- **构建**：`extract2csv.py` / `extract_aitxt.py` 提取 → 人工/AI 翻译
  `translated.csv`、`aitxt_translated.txt` → `patch_dll.py` 全量静态补丁 →
  `output/first.dll`（可带参数直接复制到 ghost master）。
- **运行环境（重要）**：幽灵始终与 `materia.exe` 同跑（master 目录内置，
  日志 `Sender: materia`；`ssp_shiori_log.txt` 为运行时日志）。`descript.txt`
  指定 `shiori.encoding,GBK` / `shiori.forceencoding,GBK`。
- **重定位**：SSP 占首选基址 0x400000 → first.dll 每次加载都被重定位；
  所有桩必须位置无关（PIC），只用相对跳转/调用 + call/pop 自定位。
- **地址约定**：**文件偏移 = VA − 0x400C00**（CODE 段）；反之为
  VA = 文件偏移 + 0x400C00。
- **构建纪律（必须保持）**：
  1. 每个代码/数据钩点在写入前**逐字节校验原值**；
  2. 每个桩有**长度断言**，cave 布局有**不重叠保证**；
  3. 追加节 `.cave` 的 RVA 固定 **0xE2000**（exitfix 有硬断言），
     任何会挤动它的资源手术都要先做（如 Teyesightform DFM 追加块）；
  4. 改 DLL 数据布局后，所有相对位移（尤其桩内以 ebx 为基址的 disp、
     缓存/标志偏移）必须同步。
- **测试工具方法**：capstone 反汇编核对、构建后逐字节 diff、
  运行中 32 位 PowerShell `ReadProcessMemory` 抽查 cave（本轮抓出过
  `\![raise,` 9 字节前缀 bug 和 `profile` 几何持久化问题）。

### 1.1 运行时状态文件（重构不涉及，但排障需知）

| 路径 | 内容 |
|---|---|
| `var/first.txt` | 能量/模式/设置开关/游戏战绩等（energychecksum 校验） |

## 2. 原版 first.dll 结构勘察（补丁相关部分）

### 2.1 PE 节表

| 节 | VA | 虚拟大小 | 原始偏移 | 备注 |
|---|---|---|---|---|
| CODE | 0x1000 | 0xAB71C | 0x400 | 代码 + dstr 常量（含本文件换算基准） |
| DATA | 0xAD000 | 0x122C | 0xABC00 | 全局/常量数据 |
| BSS | 0xAF000 | 0x3B51 | — | 零填充全局（能量、标志、指针槽） |
| .idata | 0xB3000 | 0x2708 | 0xAD000 | 导入表（IAT 槽 = 0x4Bxxxx VA；注意 RVA/VA 两套约定） |
| .edata | 0xB6000 | 0x64 | 0xAF800 | 导出表（load/request/unload；DPI/IME 补丁改这里） |
| .reloc | 0xB7000 | 0xB588 | 0xAFA00 | 重定位表（ULW 补丁必须同步删除 4+4 个条目） |
| .rsrc | 0xC3000 | 0x1E800 | 0xBB000 | DFM/AITXT 等资源（`文件 = VA − 0x8000`） |

`.cave` 为构建期追加节：RVA 0xE2000、文件 0xD9800（原始文件长度正好 = .rsrc raw 末尾）、
大小 0x8000、属性 CODE|EXECUTE|READ|WRITE。

### 2.2 关键数据结构（补丁依赖）

- **Delphi dstr 常量**：`[rc:4=-1][len:4][data]`，代码以 **data 指针**引用；
  `answer` 类型另有「大写 hex 反转」格式；`font1` 是 ShortString（off-1 长度头）。
- **请求帧**（request() 内，桩A/桩B 均在此帧）：`[ebp+8]=请求 PChar`、
  `[ebp+0xC]=长度指针`、`[ebp-0x4c]=事件名`、`[ebp-0x1c]=响应串`、
  `[ebp+0x8]/[ebp+0xC]` 之外不假设。
- **常用全局**（VA）：
  - `0x4B29E8`：菜单/点击状态机兼能量 mode（**严禁触碰**，详见 4 类补丁）
  - `0x4B2A64`：当前请求 Reference0（所有事件处理器读它）
  - `0x4B29F8`：打字游戏"当前要打文本"；`0x4ADCDC`：打字进行中标志
  - `0x46EBFC`：打字输入脚本模板 `\![raise,OnTypinggameInput,`（27B 常量）
  - `0x4ADCC0/C4/C8/D0/D4/D8`：问答战绩/倒计时；`0x4ADD08`：视力答案暂存
  - `0x4AE070`/`0x4ADFF8`：视力窗/倒计时窗对象槽；`0x4B29E0`：视力窗兼用槽
  - `0x4B08CC`/`0x4B298C`：Tnotifyform / Tfirstconfigform 对象槽
  - `0x4B31E4`/`0x4B31E0`：GetModuleHandleA / GetProcAddress 的 IAT（VA）
- **常用函数**：LStrAsg `0x403C58`、LStrCat `0x403E48`、LStrClr `0x403BC0`、
  字符串比较 `0x403F50`、Format `0x403F00`、Free `0x44C9DC`、
  ConvertAll `0x4708DC`、连接转换 `0x417048`、重定向基准 `0x400C00`。
- **窗体类**：`Ttypinggameform`（自绘输入框，回车提交即自毁 0x46EAEC）、
  `Teyesightform`（C 图窗，**唯一没写 `Scaled`** 的 DFM→双重缩放）、
  `Tcountdownform`（倒计时，关闭=隐藏）。

## 5. 重构目标与原则

1. **顺序**：文件结构与 `.cave` 分区都按 `patches.txt` 六类组织；
   每类内部按功能远近排序（数据级在前、依赖者在后）。
2. **相邻**：同功能桩紧邻；被调者（如关窗桩、helper）贴住调用者（桩A/桩B）；
   运行时同层组件（退出修复、IME、键盘、ULW）各自成块。
3. **少跳转/少避让**：桩内只用 rel8/rel32 必要跳转；消除因"挤"导致的
   rel8 溢出与 NOP 填充；不再出现"某桩为了避开另一层而飞到远处"。
4. **每桩自包含、简洁完整**：一个桩的全部常量/字符串/缓冲放在一起，
   便于审查；共享的装配器（label/fixup/溢出断言）抽成公用工具。
5. **固定层原位不动**：IME（band1/band2）、键盘、ULW 三层内部稠密、
   经大量实测，**不搬动**；退出修复系与重力语（桩+映射表）本来就是
   散件，随本轮一起归拢到各自功能区。
6. **零死代码**：删除测试保留区（0x3D00-0x3DF0 的"测试入口"注释）、
   已废弃开关、无用常量；`SHIFTJIS_OFFSETS` 已确认废弃（空集占位，
   重构时删除并简化 main 编码分支为统一 GBK）。
7. **注释规范**：每个补丁函数头 = 功能一句话 + 原理 + 钩点 + cave 布局 +
   返回值/副作用 + 已知坑；文件分区横幅与 patches.txt 编号对应。

## 10. 风险与陷阱清单（历史踩坑，重构必须避开）

1. **重定位**：绝不写构造期绝对地址（除 IAT/固定 VA 且按现约定）；
   进/出保存寄存器，`call $+5/pop` 自定位。
2. **.reloc**：ULW 4+4 个调用点替换必须同步删重定位条目，否则乱飞。
3. **SEH**：桩A 读 `[ebp-0x4c]` 必须带 SEH（无 ID 请求是栈残留）。
4. **栈平衡**：桩内联 API 调用按 stdcall 由被调方清参；建桩时逐条数栈。
5. **IAT RVA vs VA**：`_EXF_IAT_*`/`KBD_IAT_*` 是 RVA，ULW 的 `ULWFIX_IAT_*`
   是 VA——两套约定，改动前看常量注释。
6. **缓存头**：rc 在 data−4；空缓存 rc=0 不可 LStrAsg（FreeMem 崩）；
   数据区搬迁必须做重叠检查。
7. **0x4B29E8**：严禁触碰（菜单/能量共用、发送开关；历史清零全删）。
8. **未提交打字窗关闭**：必须靠 GAMELEFT 放行 CloseQuery；WM_CLOSE 静音、
   不可模拟按键（raise 打断 goodbye + 提示音）。
9. **eyebusy 保护窗口**：从 OnEy* 到"非被动双击"；反馈期吞双击防打断
   `leave,passivemode`。
10. **超时路径**：close-only 补丁 + 宿主原生兜底；勿再合成 `,timeout]`
    （已实测宿主会补发 ID 事件 Ref0=timeout；纯 SSP 例外需另议）。
11. **profile 几何**：窗体验证前先删 `profile/<窗体>.txt`，否则旧尺寸覆盖。
12. **资源手术**：Teyesightform 追加块 ≤0x800，保 `.cave` RVA；DFM 属性
    插入点取类名/实例名之后的属性表头。
13. **临时调试**：一律不留在仓库（本轮已清理 memread/dump 脚本）。
14. **主流程顺序**：见 §7 约束，尤其 IME EAT 链与键盘 load 字节的先后。

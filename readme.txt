■ 概要

さくら（樱）是最早的本体软件 MATERIA 的内置人格。
其最初的形象是仿照 PersonaWare（现 Chararina）的默认人物「春菜」（Haruna）所制，
故命名曰「伪春菜」（Nise-Haruna）。

后迫于版权压力，项目多次改名，先后更名「何か」（Nanika）、「伺か」（Ukagaka）；
内置人格也经历了如下名称变动：

- 偽春菜（Nise-Haruna）
- 任意 / 任意たん（Nin'i-tan）
- さくら（樱，Sakura）
- みかげさくら（御影樱，Mikage Sakura）

御影樱即为外观重新设计后的名称，由原来的双马尾变成现在的短发造型；
但原形象仍留有一张 Surface 图片作为彩蛋。
本项目采用的就是此版本。

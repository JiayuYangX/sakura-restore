■ 概要

主要角色：さくら（樱）
次要角色：うにゅう（乌纽）

さくら 是最早的本体软件（后定名 MATERIA）的内置人格。
其最初的形象是仿照 PersonaWare（现 Chararina）的默认人物「春菜」（Haruna）所制，
故命名曰「伪春菜」（Nise-Haruna）。

后迫于版权压力，项目多次改名，先后更名「何か」（Nanika）、「伺か」（Ukagaka）；
内置人格也经历了如下名称变动：

- 偽春菜（Nise-Haruna）
- 任意 / 任意たん（Nin'i-tan）
- さくら（樱，Sakura）
- みかげさくら（御影樱，Mikage Sakura）

「御影樱」即为外观重新设计后的名称，由原来的双马尾变成现在的短发造型；
本项目采用的就是此版本。

------------------------------------------

■ 项目介绍

本项目通过修补 first.dll 实现了以下内容：

- 全部文本汉化，涵盖对话、界面及加密文本
- 完美兼容 SSP，还原其在 MATERIA 中的所有重要特性
- 修复原版的遗留问题，优化操作逻辑

对默认外壳进行了超分抗锯齿，边缘更加平滑自然。

------------------------------------------
